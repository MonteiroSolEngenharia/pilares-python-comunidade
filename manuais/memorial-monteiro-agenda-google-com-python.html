Visão Geral do Processo

Esse fluxo tem 4 partes:

  1. Google Cloud Console → criar um "projeto" e autorizar seu app a acessar o Google Calendar (arquivo credentials.json).
  2. Ambiente Python → instalar as bibliotecas do Google.
  3. Script Python → lista de eventos + código que envia para a API do Google.
  4. Autenticação → primeira execução abre o navegador para autorizar; depois fica salvo um token e não pede de novo.
1

Criar credenciais no Google Cloud

  1. Acesse console.cloud.google.com
  2. Crie um novo projeto (ou use um existente)
  3. Menu lateral → APIs e Serviços → Biblioteca
  4. Pesquise "Google Calendar API" → clique Ativar
  5. Vá em APIs e Serviços → Tela de consentimento OAuth
    • Tipo de usuário: Externo
    • Preencha nome do app, e-mail de suporte, etc.
    • Em "Usuários de teste", adicione o e-mail da conta Google da agenda
  6. Vá em Credenciais → Criar Credenciais → ID do cliente OAuth
    • Tipo de aplicativo: App para computador (Desktop)
    • Dê um nome, crie
  7. Clique em baixar JSON — esse arquivo é o credentials.json
  8. Coloque esse arquivo na mesma pasta do script Python
⚠️ O credentials.json dá acesso à conta Google via esse app — não compartilhe publicamente (não suba pra GitHub público, por exemplo).
2

Preparar o ambiente Python

Na pasta do projeto, abra o terminal e rode:

pip install google-auth-oauthlib google-api-python-client
3

Estrutura do Script

O script tem 3 blocos principais:

Bloco A — Autenticação (não precisa tocar)

from google.oauth2.credentials import Credentials
from google_auth_oauthlib.flow import InstalledAppFlow
from googleapiclient.discovery import build
from google.auth.transport.requests import Request
import os

SCOPES = ['https://www.googleapis.com/auth/calendar']

def autenticar():
    creds = None
    if os.path.exists('token.json'):
        creds = Credentials.from_authorized_user_file('token.json', SCOPES)
    if not creds or not creds.valid:
        if creds and creds.expired and creds.refresh_token:
            creds.refresh(Request())
        else:
            flow = InstalledAppFlow.from_client_secrets_file(
                'credentials.json', SCOPES)
            creds = flow.run_local_server(port=0)
        with open('token.json', 'w') as token:
            token.write(creds.to_json())
    return build('calendar', 'v3', credentials=creds)

Bloco C — Envio para o Google Calendar

def criar_eventos(service, eventos):
    for ev in eventos:
        body = {
            'summary': ev['titulo'],
            'start': {
                'dateTime': f"{ev['data']}T{ev['hora_inicio']}:00",
                'timeZone': 'America/Sao_Paulo',
            },
            'end': {
                'dateTime': f"{ev['data']}T{ev['hora_fim']}:00",
                'timeZone': 'America/Sao_Paulo',
            },
            'reminders': {
                'useDefault': False,
                'overrides': [
                    {'method': 'popup', 'minutes': 24 * 60},
                    {'method': 'popup', 'minutes': 60},
                ],
            },
        }
        criado = service.events().insert(calendarId='primary', body=body).execute()
        print(f"✅ Criado: {ev['titulo']} ({ev['data']})")

if __name__ == '__main__':
    service = autenticar()
    criar_eventos(service, eventos)

Dúvidas Frequentes

Se eu mudar o código, ele apaga o que já está na agenda?
Não. O comando usado é events().insert(), que só cria eventos novos. Nunca deleta ou sobrescreve o que já existe. Rodar o script duas vezes com a mesma lista gera eventos duplicados, não atualiza.
Como evito duplicar se rodar de novo?
1. Manual: depois de rodar, apague do script os eventos que já foram criados, deixando só os novos.
2. Avançado: dar um ID fixo para cada evento e usar events().update() em vez de insert() quando o evento já existir.
Preciso de outro script para outro tipo de agendamento?
Não. O mesmo script serve — basta mudar a lista eventos. Se quiser organizar melhor, pode criar um script por "projeto de agenda" ou um script genérico que lê os eventos de um arquivo CSV/JSON separado.
Como apagar um evento criado por erro?
Mais simples: apague direto no Google Agenda pelo navegador/app, clicando no evento → Excluir. Não precisa de script para isso.

Resumo Rápido para o Dia a Dia

Quando quiser adicionar novos agendamentos:

  1. Abra agenda_pilares.py no VS Code
  2. Edite a lista eventos (adicione os novos blocos)
  3. Salve
  4. Rode: python agenda_pilares.py
  5. Confira no Google Agenda
Não precisa repetir a autenticação (Parte 1) nem reinstalar nada (Parte 2) — isso só é feito uma vez.
